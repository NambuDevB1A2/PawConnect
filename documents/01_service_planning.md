## 프로젝트 개요

PawConnect

**"사람과 보호동물을 연결하는 입양 플랫폼"**

부제:

> 보호동물 입양 · 봉사 · 맞춤 추천 통합 서비스
> 

#### 프로젝트 소개

PawConnect는 보호동물 보호소와 입양 희망자를 연결하는 웹 플랫폼입니다.

사용자는 보호 중인 보호동물 정보를 확인하고 입양을 신청할 수 있으며, 보호소는 보호동물 관리 및 입양 신청자를 관리할 수 있습니다.

또한 봉사활동 신청 기능과 성향 테스트 기반 보호동물 추천 기능을 제공하여 사용자의 참여를 유도하고 보호동물 입양 활성화에 기여하는 것을 목표로 합니다.

#### 프로젝트 목표

- 보호동물 입양 정보 접근성 향상
- 보호소와 입양 희망자 간 연결 지원
- 입양 프로세스의 온라인화
- 봉사 참여 활성화
- 성향 기반 추천을 통한 입양 관심도 증가

### 핵심 기능

- 보호동물 조회
- 입양/봉사 신청
- 보호소 관리

## MVP (최소 개발 사양)

- **회원 시스템**
    - 회원가입
        - Role(역할) 구분 : 개인 회원 / 보호소 관리자(기업 회원) / 홈페이지 관리자(seed 등록)
        - 역할 구분(개인/기업)에 따른 회원가입 페이지 분리
    - JWT 인증
        - 로그인
        - 토큰을 어디에 저장할지 : LocalStorage 저장 vs Http Cookie 저장
    - 마이페이지
        - 개인정보 수정
        - 보호소 관리자 → 보호소 관리자 페이지

- **홈페이지 관리자 페이지**
    - 관리기능 → 나중에 기획
    - 유저 이상 행동 / 특징 / 비고 확인 (블랙리스트/영구정지)

- **보호소 관리자 페이지 ⇒ 기업회원 마이페이지**
    - 보호동물 관리
        - 등록
        - 수정
        - 삭제
    - 입양 신청 관리
        - 승인
        - 상태 변경(면접/임시 보호 등)
        - 거절
    - 데이터 확인?
        - 입양 완료/대기 수

- **보호동물 목록 게시판**
    - 기본 : 개, 고양이 (나머지 동물 추후 업데이트)
    - 목록 조회
        - 검색 및 필터 (품종 / 성별 / 나이 / 입양 상태 등)
    - 상세 조회
    - 상세 페이지 → 댓글 작성/삭제
        - 일반 사용자는 자신의 것만 삭제 가능
        - 보호소 관리자는 다른 일반 사용자의 댓글도 삭제가능하게

- **입양 신청**
    - 개인 회원 기능
        - 입양 신청서 작성
        - 신청 내역 조회
            - 라우터 나눈걸 고민을 좀 해봐야 함
    - 보호소 관리자 기능
        - 신청 목록 조회
        - 상태 (승인/거절/면접/임시보호 등) 처리
        - 입양 상태 변경 (게시글 상태 → 입양 완료)

- **보호소 페이지**
    - 보호소 소개
        - 위치
        - 연락처
        - 등록 동물 목록

- **성향테스트) 강아지 종류 MBTI 테스트 ⇒ 차별화 기능** 🐶 "나는 어떤 견종이었을까?"
    - 종류에 따라 보호동물 입양 추천 매칭
    - 본인 매치 보호동물 결과 보기
    - 닮은 보호동물 + 잘맞는 보호동물 매칭
    
    * MVP 에서는 개와 고양이를 우선 지워하며, 향후 토끼, 조류, 파충류 등 다양한 보호동물로 확장할 예정이다.
    
- **반려동물 자랑 게시판**
    - 게시글
        - 등록
        - 수정
        - 삭제
    - AI 자동 글쓰기
    
- **AI 맞춤 분석 (LLM)**
    - Azure AI Foundry 기반 맞춤형 결과 분석
    - 성향 테스트 결과에 대한 자연어 설명 생성
    - 추천 보호동물과의 매칭 이유 제공
    - 입양 전 고려사항 및 반려생활 팁 제공
