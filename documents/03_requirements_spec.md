# 요구사항 명세서

최신: 2026-07-10


### 역할

| 이름 | Role | 설명 |
| --- | --- | --- |
| 일반 사용자 | USER | 보호동물 조회 및 입양을 신청하는 회원 |
| 보호소 관리자 | SHELTER | 보호동물을 등록하고 입양 신청을 관리하는 회원 |
| 홈페이지 관리자 | ADMIN | 시스템 운영 및 회원/보호소를 관리하는 관리자 |

### 비기능 요구사항

| 이름 | 설명 |
| --- | --- |
| 보안 | JWT 기반 사용자 인증 및 권한(Role) 기반 접근 제어를 적용한다. |
| 성능 | 주요 페이지는 3초 이내에 응답하는 것을 목표로 한다. |
| 데이터 관리 | PostgreSQL을 사용하여 데이터를 저장 및 관리한다. |
| API | REST API를 제공하며 Swagger를 통해 문서화한다. |
| 배포 | Azure Cloud 환경에 서비스를 배포한다. |
| 사용성 | 직관적인 UI/UX를 제공하며 반응형 웹을 제공한다. |
| 협업(유지보수) | GitHub를 이용한 버전 관리 및 협업 환경을 구축한다. |
